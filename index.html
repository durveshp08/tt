How this recommendation works

This is rule-based assistance, not a black box. It follows the same easy-to-check logic each time:

  • Five working days: Monday to Friday.
  • Fixed lecture, recess, and break times.
  • Labs receive a consecutive two-period block before theory is assigned.
  • Theory subjects rotate and are spread across days where possible.
  • Refresh changes the starting order only; it never adds hidden rules.
